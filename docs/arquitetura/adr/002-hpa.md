# ADR 002 — HPA

Status: aceita em 1º de novembro de 2026.

## Contexto

O cluster precisa aumentar a API quando a oficina cresce, sem arrastar o banco junto. A escala fica no manifesto da aplicação. O repositório do cluster entrega o metrics-server que alimenta essa decisão.

## Decisão

O HorizontalPodAutoscaler `autoscaling/v2` observa o Deployment `wrenchbox-api`. O mínimo é 1 réplica, o máximo é 4, a CPU média alvo é 60% e a memória média alvo é 75%. O container pede 100m de CPU e 256Mi de memória. O metrics-server do AKS, e o do Kind no laboratório, alimenta o HPA. O endpoint `GET /api/v1/diagnostics/load` continua só para administrador e fora do gateway público, para a demonstração de carga.

## Consequências

Quatro réplicas cabem num node `Standard_B2s` só por pouco tempo. O teto de 4 é uma escolha consciente para o crédito de estudante. Subir esse teto pede um node pool maior, e isso já está parametrizado no Terraform do cluster.
