# ADR 002 — HPA

- Status: aceita
- Data: 2026-11-01

## Contexto

O cluster precisa escalar a API quando a oficina cresce, sem escalar o banco junto.

## Decisão

HorizontalPodAutoscaler `autoscaling/v2` no Deployment `wrenchbox-api`: mínimo 1, máximo 4, CPU média 60% e memória média 75%. Requests do container: 100m CPU e 256Mi. O metrics-server do AKS (e o do Kind, no laboratório) alimenta o HPA. O endpoint `GET /api/v1/diagnostics/load` continua disponível só para administrador e fora do gateway público, para a demonstração.

## Consequências

Quatro réplicas cabem num node `Standard_B2s` só por pouco tempo. O teto de 4 é didático. Subir o teto exige um node pool maior, o que está parametrizado no Terraform do cluster.
